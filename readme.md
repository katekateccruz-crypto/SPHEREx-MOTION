# SPHEREx Blink & Spectra Explorer

Welcome to the official repository for the **SPHEREx Blink & Spectra Explorer**, hosted at [katekateccruz-crypto/SPHEREx-MOTION](https://github.com/katekateccruz-crypto/SPHEREx-MOTION).

## Overview
This single-file web application provides interactive exploration tools for NASA's **SPHEREx** (Spectro-Photometry of the Universe and Reionization Explorer) mission. It features:
- **Blink Comparison Viewer:** Scan through multi-epoch observations to detect high proper motion objects and transits.
- **102-Band Spectra Analyzer:** Examine continuous infrared spectra (0.75 µm – 5.0 µm) with signal-to-noise ratio (SNR) stacking.
- **Preset Target Catalog:** Quickly load famous targets like WISE 0855-0714, Barnard's Star, and Epsilon Indi B.
- **Customizable URL & Iframe Embed Generator:** Share customized views instantly.

## Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/katekateccruz-crypto/SPHEREx-MOTION.git
   cd SPHEREx-MOTION
   ```
2. Open `index.html` directly in any modern web browser or deploy it instantly via **GitHub Pages**.
